Component Documentation: TAiGeminiChat
TAiGeminiChat is a Delphi component designed to interact with Google Gemini's v1beta API. It supports the most advanced features of Gemini 1.5 and 2.0 models, including native multimodality, code execution, deep reasoning (Thinking), web search, and context caching.

1. Main Properties
Basic Configuration
Reasoning (Thinking Models)
Configuration for models capable of exposing their chain of thought (e.g., gemini-2.0-flash-thinking-exp).
Video Generation (VEO)
Specific properties when requesting video generation.

2. Special Capabilities (Tools & Media)
The chat behavior is defined by the ChatMediaSupports property (set of flags).
A. Code Interpreter (Code Execution)
Allows Gemini to write and execute Python code in a secure Google environment to solve complex math or logic.
Activation: Include tcm_code_interpreter in ChatMediaSupports.
Visualization: Code and its result appear formatted in the chat.
Restriction: Cannot be used simultaneously with Function Calling (local functions).
B. Web Search (Grounding)
Connects the model to Google Search to get updated information.
Activation: Include tcm_WebSearch in ChatMediaSupports.
Result: Consulted sources are stored in the message's WebSearchResponse property and the text includes citations.
C. Function Calling (Local Tools)
Allows the model to invoke functions in your Delphi application.
Activation: Tool_Active := True and assign a TAiFunctions component.
Flow: The model requests to execute a function -> The component executes it (even in async mode) -> The result is returned to the model -> The model generates the final response.

4. File and Cache Management (File API)
Gemini has two methods to handle large files (PDFs, Videos, Long Audios): Temporary Files and Persistent Cache.
A. Temporary Files (File API)
For one-time interactions. Files are automatically deleted after 48 hours.
UploadFile(MediaFile): Uploads a local file to Google's cloud. Returns a URI (e.g., https://...). Necessary to process heavy videos or audios.
CheckFileState(MediaFile): Verifies if an uploaded file has finished processing (necessary for videos before asking about them).
DownLoadFile(MediaFile): Downloads binary content from Google. Mainly used to download videos (.mp4) generated by the VEO model.
DeleteFile(MediaFile): Manually deletes the file from the cloud.
B. Context Cache (Context Caching)
To optimize costs and speed when using the same giant context (e.g., a book, technical manuals) across many different conversations.
UploadFileToCache(MediaFile, TTL): Uploads the file and creates a cache with a time-to-live (TTL in seconds). Returns a CacheName.
ListCaches: Returns a JSON with all active caches in your account.
RetrieveCache(CacheName): Gets metadata of a specific cache (tokens used, expiration date).
DeleteCache(CacheName): Deletes a cache before its TTL expires (to stop paying for storage).

5. Usage Example (Typical Configuration)
codeDelphi
procedure TForm1.ConfigureGemini;
begin
  AiGeminiChat1.ApiKey := 'YOUR_API_KEY';
  AiGeminiChat1.Model := 'gemini-2.0-flash';
  
  // Enable Streaming (Typewriter effect)
  AiGeminiChat1.Asynchronous := True;
  
  // Enable Visible Thinking
  AiGeminiChat1.ThinkingBudget := 1024;
  AiGeminiChat1.IncludeThoughts := True;
  
  // Enable Web Search and Code Execution
  AiGeminiChat1.ChatMediaSupports := [tcm_WebSearch, tcm_code_interpreter];
  
  // Events
  AiGeminiChat1.OnReceiveData := OnReceiveText;
  AiGeminiChat1.OnReceiveThinking := OnReceiveThinking;
end;

6. User Guide: Advanced Features
A. Async Mode (Streaming)
Allows receiving the response word by word, improving the application's perceived speed.
Configuration: AiGeminiChat.Asynchronous := True;
Events:
OnReceiveData: Fires repeatedly with each new text fragment.
OnReceiveDataEnd: Fires once when the entire response is complete.
codeDelphi
procedure TForm1.AiGeminiChat1ReceiveData(Sender: TObject; aMsg: TAiChatMessage; 
  aResponse: TJSonObject; aRole, aText: String);
begin
  // Add text to Memo without clearing previous
  MemoRespuesta.Lines.Text := MemoRespuesta.Lines.Text + aText;
end;
B. Using Functions (Function Calling)
Allows Gemini to interact with your Delphi code (e.g., query database, get system time).
Configure TAiFunctions: Drag a TAiFunctions component onto the form.
Register a Function:
Double-click TAiFunctions.
Add new function (e.g., GetStockPrice).
Define parameters (e.g., symbol type String).
Program the OnAction event to return the result.
Link:
AiGeminiChat.AiFunctions := AiFunctions1;
AiGeminiChat.Tool_Active := True;
Note: The component handles execution automatically in the background, even in async mode. Gemini will pause generation, execute your function, and continue responding with the obtained data.
C. Code Interpreter (Code Interpreter)
Allows Gemini to write and execute Python in Google's cloud. Ideal for math, graphs, or complex logic.
Activate:
codeDelphi
AiGeminiChat.ChatMediaSupports := AiGeminiChat.ChatMediaSupports + [tcm_code_interpreter];
Important Restriction: Code Interpreter and Function Calling (own functions) cannot be used in the same message. If you activate tcm_code_interpreter, the component will temporarily disable your local functions to avoid API errors.
Visualization: Python code and its result (Output) will be automatically added to the chat history formatted in Markdown.
D. Web Search (Grounding with Google Search)
Connects the model to the internet to get updated information not in its training data.
Activate:
codeDelphi
AiGeminiChat.ChatMediaSupports := AiGeminiChat.ChatMediaSupports + [tcm_WebSearch];
Result:
The text response will include the found information.
The resulting TAiChatMessage object will have the WebSearchResponse property filled with sources.
You can access the source list like this:
codeDelphi
var Source: TAiWebSearchItem;
for Source in Message.WebSearchResponse.annotations do
  MemoFuentes.Lines.Add(Source.title + ' - ' + Source.Url);
E. Comparison: When to use what?

Property | Type | Description
ApiKey | String | Your Google AI Studio API key. (e.g., @GEMINI_API_KEY to use environment variables).
Model | String | The model identifier. Examples: gemini-2.0-flash, gemini-1.5-pro, gemini-2.0-flash-thinking-exp.
Url | String | Base endpoint. Default: https://generativelanguage.googleapis.com/v1beta/.
Asynchronous | Boolean | True: Activates Streaming mode. Response arrives in fragments (typewriter effect).<br>False: Waits for entire response before returning control.

Property | Type | Description
ThinkingBudget | Integer | Number of tokens dedicated to thinking.<br>0: Disabled.<br>>0 (e.g., 1024): Activates "Thinking" mode.
IncludeThoughts | Boolean | True: Thinking text is received in OnReceiveThinking event.<br>False: The model thinks, but thinking text is hidden (only final result is seen).
ReasoningEffort | String | High-level alias. Values: 'low', 'medium', 'high'. Automatically configures thinking budget.

Property | Type | Description
VideoParams | TStrings | Key-value parameters for the Veo model.<br>- aspectRatio: '16:9', '9:16'.<br>- personGeneration: 'allow_adult', 'dont_allow'.

Event | Description
OnReceiveData | Fires each time a fragment of the final response arrives (text the user should see). Ideal for updating a Memo or ChatView in real time.
OnReceiveThinking | Fires when a fragment of the thinking process arrives. Useful for showing a collapsible "Thinking..." section in the UI.
OnFunctionCall | (Optional) Fires if the component detects a function request not automatically managed by TAiFunctions.

Need | Use... | Why
What time is it? / Data from my DB | Function Calling | Gemini has no access to your computer or real time.
Square root of 12345? | Code Interpreter | LLMs fail at math; Python is exact.
Who won yesterday's game? | Web Search | Gemini's knowledge has a cutoff date; Google Search is current.
Write a poem / Summarize | Normal Chat | It's the model's native specialty.
